### Tokenized Assets Live on Uniswap
- **URL:** https://x.com/Uniswap/status/2065799598757609833?utm_source=tldrcrypto
- **Via:** TLDR Crypto, 2026-06-16
- **Read time:** 3 minute read
- **TLDR Summary:** Uniswap has added tokenized securities, including SpaceX, Apple, Tesla, and NVIDIA, to its Web App, Wallet, and API, allowing users to discover and trade these assets within existing Uniswap interfaces. The protocol has processed $9.1 billion in RWA pool volume across 2.6 million transactions from over 140,000 wallets, with equity, fixed income, and yield-bearing instruments making up the primary asset categories. Uniswap v4's hook infrastructure lets issuers configure transfer restrictions, KYC gates, allowlists, geographic controls, and dynamic fees at the pool level, while developers using the Uniswap API gain access to tokenized securities without additional integration work. Once onchain, these assets become composable across wallets, applications, and agents and tradeable outside TradFi market hours, though issuer-imposed eligibility requirements, KYC, and jurisdictional restrictions still apply.

### Aztec Connect's Abandoned Smart Contract Exploited for $2.1M
- **URL:** https://cointelegraph.com/news/aztec-connects-depreciated-smart-contract-exploited-for-2-million?utm_source=tldrcrypto
- **Via:** TLDR Crypto, 2026-06-16
- **Read time:** 3 minute read
- **TLDR Summary:** A June 15 exploit drained approximately $2.1 million from Aztec Connect, a DeFi protocol deprecated in March 2023 whose immutable smart contracts continued holding user assets. BlockSec attributed the breach to a ZK proof verification mismatch where the verification system and Ethereum settlement logic interpreted the same transaction list differently, allowing the attacker to generate unbacked balances and execute seven withdrawals across ETH, DAI, and wrapped staked ETH. Aztec Labs confirmed it holds no admin keys and cannot pause or upgrade the contract, making any post-exploit remediation impossible.
